## 案例：用KNN和决策树预测泰坦尼克号生存分析
### 一、获取数据
数据集：https://www.kaggle.com/datasets/brendan45774/test-file  
数据分析：https://www.kaggle.com/competitions/titanic/data

### 二、数据预处理
| 变量名 | 定义 | 说明 |
|--------|------|------|
| survival (生存) | Survival | 0 = No, 1 = Yes |
| pclass (船票等级) | Ticket class | 1 = 1st, 2 = 2nd, 3 = 3rd |
| sex (性别) | Sex | |
| Age (年龄) | Age in years | |
| sibsp (兄弟姐妹/配偶数) | # of siblings / spouses aboard the Titanic | |
| parch (父母/子女数) | # of parents / children aboard the Titanic | |
| ticket (船票号) | Ticket number | |
| fare (票价) | Passenger fare | |
| cabin (船舱号) | Cabin number | |
| embarked (登船港口) | Port of Embarkation | C = Cherbourg, Q = Queenstown, S = Southampton |
